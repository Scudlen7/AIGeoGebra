# 前端视觉改版

依据已确认的 NewDesign 原型，将真实应用统一为浅色纸面与松绿色的数学工作区。

- 桌面侧栏、全屏手机菜单、浅色和深色主题，以及键盘跳过导航入口。
- 对话和真实 GeoGebra 双栏；手机使用对话／画板切换，切换不会卸载画板或丢失草稿。
- 示例起步、可折叠示例列表、模型选择、同步状态、停止生成、执行日志。
- 云端会话卡片及名称搜索；卡片插图明确标注为计算模式示意，不冒充用户画板截图。
- 分区设置页，以及统一的登录、注册、找回密码和协议页面。
- 本地字体与图标，无新增运行时依赖。许可证位于 `public/design`。

真实模型请求、GeoGebra 执行、云端保存和认证仍使用现有实现。未把原型示例数据或模拟接口带入正式应用。GeoGebra 画板继续使用其原生白色绘图区，避免深色滤镜改变数学对象的颜色。

验证入口：`npm run build`、`npm test`、`npm run test:browser`。真实 GeoGebra 验收使用 `LIVE_GEOGEBRA=1 npm run test:math`（PowerShell 设置环境变量后运行）。浏览器回归使用模拟账户与接口，不写入真实账户；实际 GeoGebra 验收以访客模式执行参考命令，不调用模型。

`NewDesign` 独立原型保留为本地设计参考，不作为生产页面入口。
