# 第一阶段：核心可靠性修复

## 改动

- 新会话在现有 `report` JSON 内增加可选 `boardXml`，保存 GeoGebra 完整 XML。命令日志仍显示最近一批的执行情况，恢复不再依赖该批命令。数据库无需迁移。
- 监听画板对象、撤销、样式和视角变化；切换模式、页面离开及账号变化时补存最后状态。没有快照的旧会话按现有命令恢复，恢复过程不再受单次 AI 调用的 24 条限制。恢复失败提供重载和清空入口。
- Esc 立即释放输入与模式切换；旧请求的文本、命令及结束回调不能修改新请求或新账号状态。代理向上游传递取消信号，取消响应流时关闭上游读取。
- 概率同步支持相同分布的 CDF 差值、算术参数和已有数值变量，并按离散右尾包含下界的规则显示区间。解析不使用 `eval`；不支持的复合表达式不会被误当成最后一个分布调用。
- 登录会话修改先写入按账号和模式隔离的本机待同步副本，失败可重试，刷新后优先恢复。同步中的新修改保留到下一次保存；迟到的云端读取或旧账号响应不能覆盖当前工作区。

## 自动验证

```sh
npm ci
npm test
npm run build
```

测试运行真实模块及编译后的 Solid 页面，使用模拟 GeoGebra、模型和 PocketBase；覆盖多轮作图与纠错后恢复、手动编辑、超过 24 条旧命令、Esc 后立即提交、同步失败后刷新重试、账号切换隔离、概率区间与代理取消。

这些测试不替代真实模型、邮件服务和 PocketBase 的完整端到端验收。打包体积优化及全项目 CI 属于后续阶段。

本轮自动验证：32 项测试通过，生产构建通过。使用旧版页面源码复跑最初四项页面回归测试时，四项均失败，修复后通过。

浏览器实测已确认真实模型连续两轮作图（三角形、高及中点）在切换至 3D 后返回仍完整显示；正态分布 CDF 差值显示上下界 1、2，概率为 0.13591；泊松分布右尾下界为 4，概率为 0.35277，菜单也正确刷新为泊松分布。

## 真实环境验收步骤

1. 四种模式分别完成一次计算或作图；几何模式连续两轮添加对象，手动拖动一点，再切换模式或刷新，核对全部对象及位置。
2. 在模型流式响应期间按 Esc，立即再次提交；确认可继续使用，且旧响应不再进入新会话。
3. 概率模式分别计算 `Normal(0,1,2,true)-Normal(0,1,1,true)` 与 `1-Poisson(3,4-1,true)`，核对图中区间分别为 1 到 2、右尾从 4 开始。
4. 测试账号完成作图后模拟 PocketBase 不可达，确认可恢复本机副本；恢复服务后重试，重新打开云端会话核对完整图形。
5. 在请求或保存过程中退出并切换测试账号，确认对话、图形和待同步副本相互隔离；再回原账号核对其待同步修改。

## 数据边界

- 旧版本未保存的早期命令无法从最后一批日志反推；保留旧格式兼容，不承诺恢复此前已丢失内容。
- 待同步副本依赖浏览器本地存储，清理 `aiggb.*` 缓存会删除副本。超出浏览器容量或 PocketBase 报告字段大小时，需保留页面处理同步错误。
- 本阶段未改变匿名调用策略和用量计费口径，调用额度、监测、备份部署由后续生产阶段处理。
